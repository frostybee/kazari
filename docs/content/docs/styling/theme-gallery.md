Nuri ships 65 VS Code themes. Each block below renders the same Go snippet in a single theme so you can compare colors across families. The theme name matches the string you pass to `WithThemes()` or the `theme=` meta token.

### GitHub

:::columns
:::column
**github-dark**

```go wrap title="github-dark" theme="github-dark,github-dark"
package main

import "fmt"

// Greet returns a greeting for the given name.
func Greet(name string, times int) string {
    if times <= 0 {
        return "Hello, stranger!"
    }
    return fmt.Sprintf("Hello, %s! (%d)", name, times)
}
```
